# SunFlow 360 — Backend & Solar Engineering Glossary

A quick-reference guide defining key terms used across the SunFlow 360 codebase.

---

## 1. Solar & Electrical Engineering Terms

| Term | Full Name | Definition in SunFlow 360 |
|---|---|---|
| **kWp** | Kilowatt Peak | The maximum nominal DC power output of a solar array under Standard Test Conditions (STC: $1000\text{ W/m}^2$, $25^\circ\text{C}$). |
| **Mono PERC** | Monocrystalline Passivated Emitter and Rear Cell | High-efficiency solar PV cell technology used in our default 540W modules (`MOD-540W-MONO`). |
| **BOM** | Bill of Materials | Comprehensive inventory list of physical hardware required to install a solar plant (panels, inverter, cabling, structures, circuit breakers). |
| **BOS** | Balance of System | All auxiliary hardware components supporting the solar array excluding the panels and inverter (cables, connectors, combiner boxes, conduit). |
| **Inverter** | Solar Inverter | Power electronics device converting direct current (DC) generated by panels into grid-synchronized alternating current (AC) at 230V/415V. |
| **ACDB** | AC Distribution Box | Enclosure housing MCBs and Surge Protection Devices (SPDs) between the solar inverter and the consumer load/grid. |
| **SPD** | Surge Protection Device | Voltage-clamping device protecting inverters and appliances from lightning strikes and grid voltage transients. |
| **DISCOM** | Distribution Company | State electricity utility (e.g. MSEDCL, BESCOM) responsible for grid interconnection and net-meter approvals. |
| **Net Metering** | Bi-directional Metering | Utility metering arrangement crediting the homeowner for surplus solar power exported to the public grid. |
| **PM Surya Ghar** | PM Surya Ghar: Muft Bijli Yojana | Central Government solar subsidy scheme providing direct capital subsidies up to ₹78,000 for residential rooftop systems. |
| **Composite GST** | Composite Tax Supply | Indian tax rule taxing solar EPC projects at an effective 13.80% (70% goods @ 12% GST + 30% civil works/services @ 18% GST). |

## 2. Software & Architecture Terms

| Term | Definition in SunFlow 360 |
|---|---|
| **Survey Gate** | The domain invariant in `QuotationService` that blocks finalizing or sending a quotation until the site survey is marked `APPROVED`. |
| **DTO (Data Transfer Object)** | Decoupled payload objects (e.g. `QuotationCreateRequest`, `LeadResponse`) isolating database entity schemas from the public REST API. |
| **Spring Data JPA** | Framework abstracting data access via repository interfaces (`LeadRepository`), reducing boilerplate CRUD queries to method names. |
| **Flyway** | Version-controlled database migration framework executing SQL scripts (`V1` to `V11`) during application boot to ensure schema consistency. |
| **JWT (JSON Web Token)** | Stateless, cryptographically signed token containing user identity and role claims, passed in the HTTP `Authorization: Bearer` header. |
| **BCrypt** | One-way adaptive cryptographic hashing algorithm with salting used to protect user passwords in the `users` table. |
| **Stateless Session** | Server configuration where no user session state is stored in RAM; every incoming request is authenticated independently via token. |
| **CORS** | Cross-Origin Resource Sharing security mechanism allowing the browser at `http://localhost:8443` to call backend APIs at `http://localhost:8081`. |
| **ACID Compliance** | Database guarantees (Atomicity, Consistency, Isolation, Durability) provided by PostgreSQL for financial and order transactions. |
| **IoC / Dependency Injection**| Design pattern where Spring manages object lifecycles and automatically injects dependencies via constructors into services and controllers. |
